# ابزار راست‌چین‌سازی زیرنویس SRT

> توسعه‌یافته با رویکرد **Vibe Coding** (کدنویسی مبتنی بر هدایت هوش مصنوعی و پرامپت‌نویسی).

این ابزار تحت وب، فایل‌های زیرنویس با فرمت `.srt` را پردازش کرده و با اعمال استاندارد RTL (راست‌به‌چپ)، از به‌هم‌ریختگی نمایش متون ترکیبی (فارسی و انگلیسی) در پخش‌کننده‌های ویدیو جلوگیری می‌کند.

## ویژگی‌ها
- حفظ دقیق زمان‌بندی‌ها (Timecodes) و ساختار استاندارد SRT
- اصلاح جهت‌نویسی (Directionality) برای متون دوزبانه
- پردازش سریع، امن و بدون نیاز به نصب نرم‌افزار جانبی

## نحوه استفاده
۱. بارگذاری فایل `.srt` یا ورود مستقیم متن زیرنویس در ورودی برنامه.
۲. اجرای عملیات تبدیل.
۳. دریافت و ذخیره فایل اصلاح‌شده جهت استفاده در Media Playerها.

## درباره Vibe Coding
توسعه این پروژه بر پایه متدولوژی Vibe Coding صورت گرفته است؛ به این معنا که منطق، طراحی و پیاده‌سازی کدها تماماً از طریق هدایت و پرامپت‌نویسی توسط مدل‌های هوش مصنوعی انجام شده و توسعه‌دهنده نقش مدیریتی و نظارتی بر فرآیند تولید کد داشته است.
